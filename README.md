# 知识回顾问答助手

输入一个知识点关键词，例如 `dropout`，助手会进入一来一回的问答回顾：

- 每轮只问一题
- 先用判断题、单选题、多选题练客观识别
- 客观题熟练后，再进入简答题检查表达和迁移
- 你回答后，系统评估回答是否合理
- 评估会给出依据、正确点、错误点、遗漏点和下一题
- 达到掌握标准后结束本轮复习

## 配置

复制环境变量示例：

```bash
cp .env.example .env
```

在 `.env` 中填入 DeepSeek API Key：

```bash
DEEPSEEK_API_KEY=sk-your-deepseek-api-key
```

## 启动

```bash
npm start
```

打开：

```text
http://localhost:5177
```

## 设计原则

项目不读取本地知识库。所有题目生成和答案评估都通过 DeepSeek API 完成。

题型路径：

```text
判断题 → 单选题 → 多选题 → 循环加深
```

系统会持续循环客观题；只要客观题数量、正确率和知识阶段覆盖达标，即使不做简答题，也可以完成本轮复盘。

掌握判定由后端控制，不完全依赖模型自评。默认要求：

- 至少完成 30 道客观题
- 客观题整体正确率达到 85% 及以上
- 至少覆盖 5 个知识阶段
- 最近 3 轮平均分达到 85 分及以上
- 当前题评分达到 85 分及以上
- 最近 3 轮没有低于 75 分的薄弱回答
- 当前评估没有 `needsVerification`，没有错误点，且关键遗漏不超过 1 条

简答题是可选的表达检查，不再是完成复盘的必要条件。

为了降低幻觉风险，后端提示词要求模型：

- 只基于公认教材级知识和用户回答进行判断
- 每次评估列出判断依据
- 对不确定或超出常识范围的内容标记 `needsVerification`
- 不编造论文、链接、精确数字或不存在的引用

注意：任何大模型都不能绝对保证零幻觉。这个项目把“列依据、标不确定、避免假引用”作为产品约束来降低风险。
